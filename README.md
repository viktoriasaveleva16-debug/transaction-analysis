# Анализ транзакций торговых точек

Проект посвящён анализу транзакций торговых точек, поиску аномалий в работе серверов и созданию интерактивного дашборда.

## Цель проекта

Проанализировать динамику транзакций, выявить причины резких изменений показателей и подготовить дашборд для мониторинга работы торговых точек.

## Выполненные задачи

- проведён анализ количества и суммы транзакций;
- выполнено сравнение торговых точек и серверов;
- проанализирована длительность проведения операций;
- выявлены аномальные изменения нагрузки;
- оценено влияние акции на количество транзакций и средний чек;
- создан интерактивный дашборд с фильтрами.

## Инструменты

- Microsoft Excel;
- Google Sheets;
- сводные таблицы;
- формулы Excel;
- диаграммы и визуализация данных.

## Результаты

В ходе анализа были обнаружены резкие изменения количества транзакций по отдельным торговым точкам и серверам. Определены возможные причины аномалий и подготовлен интерактивный дашборд, позволяющий отслеживать сумму, количество и средний размер платежей.

## Материалы проекта
